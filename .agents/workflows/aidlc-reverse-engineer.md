# AI-DLC: Reverse Engineer Codebase

Analyze the existing codebase and generate comprehensive design artifacts.

## Instructions

1. Read `.aidlc-rule-details/inception/reverse-engineering.md` for detailed steps
2. Execute the full reverse engineering process:
   - Multi-package discovery
   - Business context analysis
   - Architecture documentation
   - Code structure documentation
   - API documentation
   - Component inventory
   - Technology stack documentation
   - Dependencies documentation
   - Code quality assessment
3. Generate all artifacts in `aidlc-docs/inception/reverse-engineering/`
4. Present completion message and wait for user approval
5. Log all findings in `aidlc-docs/audit.md`

Follow ALL rules defined in `.agents/rules/aidlc-core.md` and `.agents/rules/aidlc-mandatory-behaviors.md`.
