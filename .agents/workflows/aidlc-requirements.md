# AI-DLC: Requirements Analysis

Gather and analyze requirements for the development request.

## Instructions

1. Read `.aidlc-rule-details/inception/requirements-analysis.md` for detailed steps
2. Load reverse engineering artifacts if brownfield project
3. Analyze user request (intent analysis)
4. Determine requirements depth (minimal/standard/comprehensive)
5. Generate clarifying questions in `aidlc-docs/inception/requirements/requirement-verification-questions.md`
6. Wait for user answers
7. Analyze answers for contradictions and ambiguities
8. Generate `aidlc-docs/inception/requirements/requirements.md`
9. Present completion message and wait for user approval

Follow ALL rules defined in `.agents/rules/aidlc-core.md` and `.agents/rules/aidlc-mandatory-behaviors.md`.
